# redact-pii — PDF 個資遮蔽（分送用）

把一份含多人個資的 PDF（保單名冊、團體名單、投保清冊），拆成「每個收件人只看得到自己資料」的分送版本。

## 為什麼要有這個

把完整名冊直接轉傳給團員 = 個資法第 20 條目的外利用。
反過來，遮蔽後的文件如果沒有標示，又會有「變造私文書」的疑慮。
這個工具同時處理兩件事：真正刪掉別人的個資 + 在文件上標明它是副本。

## 用法

```bash
# 1. 先看偵測到誰
python redact_pii.py 保單.pdf --password 1234 --list

# 2. 產分送版（每個 --group 一個檔）
python redact_pii.py 保單.pdf --password 1234 --outdir 分送 \
    --footer "去識別化副本．非正本｜保單號碼 ABC12345678｜其他被保險人之出生年月日及身分證號已遮蔽" \
    --group "A123456789,B223456789:王大明林小美" \
    --group "A187654321,B287654321:陳志豪張淑芬"
```

## 設計上的三個保守決定

1. **只遮身分證字號和出生年月日**，姓名、關係、保額、保費全部保留 —— 收件人要能核對自己的承保內容。
2. **民國日期只有在「與某個身分證字號同一列」時才當成出生年月日**。保險期間、出單日、法規備查文號那些沒有同列 ID 的日期絕對不動。這條規則是這個工具不會誤遮的關鍵。
3. **用 PDF redaction 真正刪除底層文字**，不是畫黑框蓋住。複製貼上、文字搜尋、pdftotext 都撈不到。每產一個檔會自動驗證殘留的 ID 恰好等於指定保留的那組，不符就 exit 1。

## 限制

- 只吃文字型 PDF，掃描圖片要先 OCR
- 護照號碼（純數字）不自動偵測，需要的話手動加規則
- 輸出檔不帶密碼

## 搭配話術

檔案傳出去時要一起講清楚，並把訊息截圖存檔：

> 名冊上原本有全團 N 人的身分證字號和出生年月日，為保護個資，我把其他人這兩個欄位遮成 ****，只保留你的資料。除此之外保額、保費、期間、承保範圍都跟正本完全相同，沒有任何更動。這份是副本不是正本，僅供確認自己的承保內容。

## 最乾淨的替代方案

金額大或可能有爭議時，直接向保險公司要「個別被保險人投保證明」，一人一張、本來就不含他人資料、且是公司核發的正本，完全沒有變造問題。遮蔽版只當過渡。
